# GeoPulse 🌍

GeoPulse is a real-time geopolitical monitoring dashboard that visualizes global conflicts, disasters, aviation activity, market movements, and breaking news through an interactive world interface.

The platform provides a command-center style dashboard with modular widgets and live data feeds, allowing users to monitor global developments in one place.

---

## Features

- 🌍 Interactive global map and 3D globe
- ⚔️ Conflict zone monitoring
- ✈️ Live flight tracking
- 🌋 Earthquake monitoring
- 🌪 Disaster event tracking
- 📰 Geopolitical news feed
- 📈 Global market monitoring
- 📺 Live news streams
- 🧩 Modular dashboard widgets
- 🗺️ Real-time global situational awareness

---

## Tech Stack

GeoPulse is built using modern web technologies:

- **React**
- **TypeScript**
- **Vite**
- **TailwindCSS**
- **React Grid Layout**
- **Leaflet / React-Leaflet**
- **OpenStreetMap**

---

## Data Sources

GeoPulse integrates several open data sources including:

- News APIs for geopolitical updates
- Alpha Vantage for market data
- OpenSky Network for aviation tracking
- USGS for earthquake monitoring
- NASA EONET for disaster events

These sources allow the dashboard to display real-time global activity and monitoring data.
